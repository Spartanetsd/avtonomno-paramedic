# Автономно — файли для GitHub без вкладених папок

Завантажте **усі три файли** `index.html`, `styles.css`, `policeman-paramedic.webp` в **корінь** репозиторію. Підпапки не потрібні.

Якщо у вашому репозиторії вже існує `index.html`, завантаження цієї демоверсії **замінить** головну сторінку; зробіть резервну копію, якщо потрібно зберегти поточний сайт.

У GitHub: Add file → Upload files → оберіть окремі файли → Commit changes. Для GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

Це **демонстраційний макет**, а не автоматичне оновлення поточного застосунку. Фраза про рекомендацію потребує згоди реальних фахівців; не означає офіційного схвалення Нацполіції. Перевірте права на фотографію.
